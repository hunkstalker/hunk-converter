# Release 1.0.0

Fecha: 2026-10-29

## Decisión

Se prepara la primera release estable `1.0.0`. La aplicación se considera
terminada funcionalmente: conversión, comparador, cuentagotas, historial de
colores, ICO, AVIF/JPEG XL, idiomas, persistencia y build portable.

## Cambios

- Versión de `Cargo.toml` y `Cargo.lock` actualizada a `1.0.0`.
- Nombre visible actualizado a **HUNK Converter** en cabecera, ventana, documentación y paquetes.
- Capturas regeneradas con el pie `v1.0.0`.
- README, `proyecto.md`, `retomar.md`, arquitectura y benchmark actualizados.
- Documentación de CI en `docs/ci.md`.
- Workflow `.github/workflows/ci.yml`:
  - pruebas previas;
  - Linux Debian x86_64 en Ubuntu 22.04;
  - Windows 10/11 x86_64 con MSVC;
  - macOS universal `arm64 + x86_64`;
  - checksums y GitHub Release al empujar un tag.
- `scripts/build_dist.sh` admite `macos` y empaqueta `HUNK Converter.app` con `icon.icns`.
- Icono nativo completado desde `assets/branding/hunk-converter.png`: `icon.ico` embebido en el `.exe` con `winresource`, `icon.icns` en macOS y `.desktop` + PNG en Linux.
- Orientación EXIF aplicada al cargar JPG/WebP, con pruebas para 1, 3, 6 y 8.
- CI: NASM instalado también en el job de pruebas para compilar `rav1d`.
- Cierre de tareas: t-10 completada; t-17 descartada; t-24 absorbida por t-23.
- Suite actualizada a **29 pruebas**.

## Publicación

El repositorio local queda con el tag `v1.0.0` apuntando al commit final. Para
publicarlo:

```bash
git push origin main
git push origin v1.0.0
```

El push del tag dispara la build multiplataforma y la GitHub Release. Requiere
credenciales de GitHub configuradas en el entorno.
